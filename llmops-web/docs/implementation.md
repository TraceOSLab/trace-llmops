# 实现与验证说明

## 设计

界面采用暖白 `#F7F8FA`、正文 `#182230`、主色 `#0F766E`。Arco 变量同时应用于 `:root` 和 `body`，避免组件默认变量覆盖主题。侧栏宽 224px；桌面、平板和手机分别检查 1440、1024、390px。手机使用抽屉导航、单列资源卡片与全宽聊天。

工作台展示现有列表返回的最近资源，不新增聚合统计接口。应用配置按模型、任务和能力组织，调试常驻右栏；工作流使用节点库、画布、属性侧栏与底部运行面板。复杂业务表单由课程功能迁移并适配，避免丢失已有操作。

## 数据与保存

普通请求独立创建 headers，避免退出后沿用旧 Authorization；超时会真正 abort fetch，非 2xx 与业务错误均 reject，上传的网络错误、超时、取消也会结束 Promise。账号凭证失效只清理本应用的凭证与账号键，不清空浏览器其他数据。

应用写请求按应用 ID 串行；提示词防抖时立刻显示待保存状态，发布和调试会先排空防抖及请求队列。发生失败后保留后续写入顺序，用户重试后依次提交，避免旧写入覆盖新内容。工作流草稿是完整快照，保留未完成节点于本地，显式保存时提交；保存失败不丢弃画布内容。节点表单与画布均检测未保存更改。

工作流后端返回的 `language_model_config` 在边界转换为输入别名 `model_config`，不同时提交两个互相冲突的字段。模型名称允许包含 `/`。切换模型只在用户选择时发生，不默认覆盖已有模型。

## SSE 与用量

客户端按完整空行分隔的帧解析，不将网络 chunk 等同于事件；支持 UTF-8 分片、CRLF、多行 data。Agent 终止事件是 `agent_end`、`error`、`stop`、`timeout`；终止后关闭 reader，不继续累加。Agent EOF 缺少终止或尾帧不完整视为中断；工作流和提示词优化沿用各自 EOF 结束语义。

同一步骤的文本追加，结算快照覆盖。消息级用量来自终止事件，历史没有快照时显示暂无数据。未知价格不显示成免费；汇总分析旧接口缺少完整性元信息，单独提示该边界。

断开浏览器连接不保证模型请求取消；UI 的停止操作调用后端 stop 路由。没有引入 `Last-Event-ID`、重放或自动重发。契约参考仓库 `docs/contracts/agent-stream-events.md`，此次只实现消费端，不修改该契约。

## 验证边界

自动测试采用本地响应与模拟 SSE，覆盖网络分片、结束/报错、保存队列、图转换以及浏览器关键业务路径。浏览器测试针对生产构建，并拦截外部请求。完整验证结果见交付记录；截图中的账号、资源、金额、模型和回答均为明确的测试夹具，正常应用不注入这些数据。
